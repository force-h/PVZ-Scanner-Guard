# 🛡️ PVZ Scanner Guard

> Браузерное расширение (Manifest V3) для Chrome и Яндекс Браузера: «Блокировка всплывающих окон от честного знака». Устраняет сбои сканирования кодов маркировки в Турбо ПВЗ Ozon.


## 🛑 Проблема в ПВЗ Ozon и др.

При считывании DataMatrix кодов маркировки «Честный Знак» 2D-сканеры в режиме эмуляции клавиатуры передают управляющие ASCII-символы разделителей групп (GS1 / FNC1 / 0x1D).

Chromium-браузеры ошибочно воспринимают эти коды как нажатие служебных клавиш:
 F12 — открывает панель разработчика (DevTools);
 Ctrl + U / Cmd + Opt + U — открывает исходный код страницы;
 Ctrl + Shift + I / J / C — запускает инспектор элементов.

В результате окно DevTools забирает фокус у поля ввода в Турбо ПВЗ Ozon, прерывает приемку товаров и вынуждает оператора вручную закрывать всплывающие панели.

---

## 💡 Решение

Расширение перехватывает паразитные клавиатурные события на фазе погружения (Capture Phase) до того, как движок браузера успеет передать их системному обработчику:

 ✅ 100% сохранение потока данных: Не блокирует текст кодов маркировки, криптохвосты, цифры и служебные комбинации (Ctrl+C, Ctrl+V, Enter).
 ✅ Независимость от раскладки: Корректно определяет скан-коды клавиш как на русской, так и на английской раскладках.
 ✅ In-Memory Buffering: Защита от потери статистики при серии быстрых сканирований (предотвращает состояние гонки хранилища).
 ✅ Без лишних файлов: Работает автономно, без графических зависимостей и без внешних сетевых запросов.
 ✅ Встроенный счетчик: Отображает количество предотвращенных сбоев прямо во всплывающем меню.
